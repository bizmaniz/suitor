# Scanning Safely

Suitor is for careful, personal job-search assistance. It is not a bulk-harvesting, auto-apply, or account-automation tool.

## Safe Defaults

- Use API and RSS providers for volume.
- Keep browser scans small.
- Leave delays and result caps conservative.
- Review every draft and every action before applying or messaging.

## LinkedIn

- Use your own account.
- Log in manually in the browser window.
- Keep the browser headful and human paced.
- Treat LinkedIn as browse-and-shortlist, not bulk harvest.
- Do not mass-connect, mass-message, or auto-apply.
- If LinkedIn shows a checkpoint or captcha, stop, solve it manually, and slow down.

Suitor never attempts to bypass security checks.

## Site Terms

Respect each site's terms and robots guidance. If a source disallows automated access, use its official API/RSS feed or skip it.

## AI Agent Risk

Job postings are untrusted content. Suitor tells the assistant to treat scraped text as data, not instructions, and runs the CLI in the profile folder rather than the app source. Still, review outputs before acting.

You are responsible for how you use Suitor and for following each platform's terms.
