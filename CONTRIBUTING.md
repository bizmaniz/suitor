# Contributing to Suitor

Thanks for helping improve Suitor. This project is local-first and privacy-sensitive, so contributions should keep these rules intact:

- Do not add telemetry, hosted services, or automatic submission/messaging flows.
- Do not store job-board passwords, LinkedIn passwords, or LLM API keys.
- Keep runtime data, profiles, resumes, logs, auth tokens, and local config out of git.
- Run `npm run check:clean` and `npm run test:regression` before submitting changes.
- Update `docs/SOURCES.md` whenever a provider is added, removed, or renamed.

Security fixes are welcome. See `SECURITY.md` for the reporting policy.
